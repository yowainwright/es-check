## Installation

From your project directory, install ES Check as a development dependency. It requires Node.js 18 or later.

```bash copy
npm install --save-dev es-check
```

## Check a bundle

Build your project, then run the check against the files it produced. This example checks every JavaScript file under `dist/` for ES5 syntax. Adjust the target and glob to match your build.

```bash copy
npx es-check es5 './dist/**/*.js'
```

## Read the result

A passing check exits with status 0. A syntax error exits with status 1 and identifies the file and position. For example, this line in an ES5 bundle contains an arrow function:

```js
var names = ["Ada", "Lin"];
var lengths = names.map(name => name.length);
```

For `dist/bundle.js`, the diagnostic includes these lines.

```text
· erroring file: ./dist/bundle.js at ./dist/bundle.js:2:30
· error: SyntaxError: Unexpected token (2:30)
```

Line 2 uses ES2015 syntax. If you need ES5, update your build to transform arrow functions, rebuild, and run the check again.

To run the same check on every build, see [CI integration](/docs/ci-integration). For reusable targets and file patterns, see [Configuration](/docs/configuration).
