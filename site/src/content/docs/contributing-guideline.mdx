## Getting Started

Fork [ES Check on GitHub](https://github.com/yowainwright/es-check/fork). Clone your fork, add the original repository as `upstream`, and create a branch. Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/es-check.git
cd es-check
git remote add upstream https://github.com/yowainwright/es-check.git
git switch -c feature/your-change
```

Install the project tools with [mise](https://mise.jdx.dev/getting-started.html), then install dependencies.

```bash
mise install
pnpm install --frozen-lockfile
```

## Submit a pull request

1. Add tests for the behavior you changed and update the affected docs.
2. Run `pnpm lint` and `pnpm test` from the repository root.
3. Commit your changes with a descriptive message and push your branch to your fork.
4. Open a pull request against `main`. Describe the problem, explain the change, link any related issue, and respond to review comments.

Contributions use ES Check’s [MIT license](https://github.com/yowainwright/es-check/blob/main/LICENSE).

## Report an issue

Search [existing issues](https://github.com/yowainwright/es-check/issues) first. If someone has reported the same problem, add your findings there. Otherwise, [open an issue](https://github.com/yowainwright/es-check/issues/new) with a descriptive title.

For a bug, include steps to reproduce it, your ES Check and Node.js versions, and the output you expected and received. For a feature request, describe the use case. Add a code sample or screenshot when it helps explain the issue.

## Homepage banner

Open the [homepage banner](/hero/) to take a screenshot for a social post. To capture local changes, run `pnpm dev` from the repository root and open `/es-check/hero/` on the local server.

Capture the banner in light mode at 1280 × 640 and save it as `site/public/social-preview.png`. The website uses that image for link previews. Upload the same PNG under **Settings → Social preview** in the GitHub repository.
